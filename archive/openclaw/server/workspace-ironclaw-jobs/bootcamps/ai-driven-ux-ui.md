# AI-Driven UX/UI Design Bootcamp

## Course Info
- **Duration:** 360 hours + 40h prework, 9 weeks full-time
- **Level:** Beginner to Junior
- **DB slug:** `ai-driven-ux-ui`

## Stack & Technologies
Figma, Framer, HTML/CSS, Figma AI plugins, ChatGPT, FigJam AI, Midjourney (moodboards), Stark (accessibility), WAVE (accessibility audit), Dev Tools (browser), Design Thinking methodology, Agile/Lean

## Key Skills
- Design Thinking: user research, personas, user journey maps, problem statements
- UX Research: user interviews, usability testing, affinity diagrams, card sorting
- Information Architecture and sitemap design
- Wireframing (lo-fi, mid-fi, hi-fi) in Figma
- Interactive prototyping (Figma + Framer)
- UI Design: color theory, typography, design systems, atomic design, CRAP principles
- Responsive web design
- Accessibility auditing (manual + AI tools: Stark, WAVE)
- Design handoff (Figma Dev Mode, HTML/CSS basics for developer collaboration)
- AI-assisted workflows: research synthesis, moodboard generation, accessibility checks
- Voice-first and multimodal interface design

## Language Note
Design agencies and tech companies frequently hire English-speaking designers, especially for international products. Portfolio quality is more important than German fluency in most design roles. Berlin's design scene is strongly international. German agencies targeting local/consumer markets may require B1 German for client communication.
