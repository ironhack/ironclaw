# Data Analytics Bootcamp

## Course Info
- **Duration:** 360 hours + 30h prework, 9 weeks full-time
- **Level:** Beginner to Junior
- **DB slug:** `data-analytics`

## Stack & Technologies
Python, Pandas, NumPy, SQL (MySQL, SQLite), Tableau, Power BI, Scikit-learn, APIs, Web Scraping, Matplotlib/Seaborn, Jupyter Notebooks, Git/GitHub, LLMs (intro), cloud computing (intro)

## Key Skills
- Python programming for data analysis (data structures, functions, OOP, regex)
- Data wrangling: cleaning, merging, aggregating datasets with Pandas
- Data retrieval: SQL queries, APIs, web scraping
- Exploratory Data Analysis (EDA): univariate, bivariate, multivariate analysis
- Statistical inference: hypothesis testing, correlation, probability distributions
- Data visualization and storytelling: Tableau, Seaborn, interactive dashboards
- Machine learning: supervised and unsupervised algorithms (classification, regression, clustering) with Scikit-learn
- Model evaluation: accuracy, precision, recall, F1, MAE, MSE, R²
- Agile workflows (Scrum, Kanban)

## Language Note
Data roles at international companies are English-first. German-language skills become more relevant when the role involves reporting directly to German-speaking stakeholders or preparing reports in German. SQL, Python, and Tableau/Power BI skills are universal — language is secondary to technical ability for pure analyst roles.
