# AI Engineering Bootcamp

## Course Info
- **Duration:** 400 hours (360 + 40h prework), 9 weeks full-time
- **Level:** Beginner to Junior
- **DB slug:** `ai-engineering`

## Stack & Technologies
Python, NumPy, Pandas, Scikit-learn, TensorFlow/Keras, PyTorch, Hugging Face Transformers, LangChain, LangSmith, ChromaDB, OpenAI GPT-4, CLIP (multimodal), MLflow, AWS (cloud deployment), Giskard (LLM evaluation), PEFT/LoRA/QLoRA (fine-tuning), Jupyter Notebooks, Git/GitHub

## Key Skills
- Machine learning: regression, classification, clustering, SVMs, decision trees
- Deep learning: neural networks, CNNs (image classification), RNNs
- Natural Language Processing: embeddings, transformers, text generation, sentiment analysis
- LLM fine-tuning with LoRA/PEFT techniques
- RAG systems (Retrieval Augmented Generation) with ChromaDB
- LangChain agents: memory management, tool use, multi-modal search
- LLM evaluation: BLEU, ROUGE, LangSmith, Giskard
- MLOps: model deployment, experiment tracking with MLflow, AWS cloud setup
- Generative AI and prompt engineering
