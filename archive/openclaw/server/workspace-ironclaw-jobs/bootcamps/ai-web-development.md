# AI Web Development (JavaScript + React with AI Integration)

## Course Info
- **Duration:** 360 hours + 40h prework, 9 weeks full-time
- **Level:** Beginner to Junior
- **DB slug:** `ai-web-development`

## Stack & Technologies
HTML5, CSS3, JavaScript (ES6+), React, Node.js, Express.js, MongoDB, Mongoose, REST APIs, Git/GitHub, Vite, NPM, Fly.io, Netlify, Codeium, MERN stack, prompt engineering, AI-assisted development (ChatGPT, Claude)

## Key Skills
- Full-stack web development (MERN: MongoDB, Express, React, Node.js)
- Frontend: React components, hooks, state management, routing, forms, responsive design
- Backend: REST API design, Express middleware, MongoDB CRUD, authentication (JWT)
- Agile methodology (standups, retrospectives, MVP scoping)
- Cloud deployment (Fly.io, Netlify)
- AI-assisted development workflow
