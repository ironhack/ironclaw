# Data Engineering Bootcamp

## Course Info
- **Duration:** 360 hours + 40h prework, 9 weeks full-time
- **Level:** Beginner to Junior
- **DB slug:** `data-engineering`

## Stack & Technologies
Python (3.10+), SQL, Apache Airflow (workflow orchestration), dbt (Data Build Tool, in-warehouse transformations), Apache Spark/PySpark (distributed processing), Apache Kafka (real-time streaming), Apache NiFi (data flow automation), Snowflake, BigQuery, Redshift (cloud data warehouses), Terraform, Docker, Great Expectations (data validation), Grafana, Apache Superset, Power BI, Git/GitHub, PostgreSQL, MongoDB, AWS/GCP (cloud deployment)

## Key Skills
- ETL/ELT pipeline design and implementation
- Batch data processing with Python, Pandas, and Spark
- Pipeline orchestration with Apache Airflow (DAGs, scheduling, dependencies)
- In-warehouse data transformations with dbt (modular models, testing, lineage)
- Real-time streaming with Kafka and Spark Structured Streaming
- Visual data routing with Apache NiFi
- Cloud data warehousing: Snowflake, BigQuery, Redshift
- Infrastructure automation with Terraform and Docker
- Data validation and quality testing (Great Expectations)
- Data governance: GDPR compliance, PII masking, lineage tracking
- CI/CD for data pipelines

## Language Note
Data engineering is infrastructure-heavy and globally standardized — English is the working language at international companies and data teams. Airflow, Kafka, Spark, and dbt expertise are rare enough that employers frequently waive language requirements to find qualified candidates. Key sectors: fintech (Frankfurt), e-commerce (Berlin, Hamburg), automotive data platforms (Munich, Stuttgart).
