# AI Consulting & Integration Bootcamp

## Course Info
- **Duration:** 360 hours + 40h prework, 9 weeks full-time
- **Level:** Beginner to Junior (business/consulting focus, non-technical background welcome)
- **DB slug:** `ai-consulting-integration`

## Stack & Technologies
Python (3.11+), n8n (workflow automation), OpenAI API, Anthropic API, Google Gemini API, LangChain, LangSmith, Power BI, Tableau, RAG (Retrieval Augmented Generation), MCP (Model Context Protocol), Agile (Kanban, XP), Jira, Trello, Miro, Canva, Git/GitHub

## Key Skills
- AI workflow automation (no-code via n8n; code via Python)
- RAG architecture and implementation
- Multi-LLM orchestration (OpenAI + Anthropic + Gemini)
- Prompt engineering and LLM evaluation (A/B testing, hallucination detection)
- Agentic AI design patterns and autonomous decision-making systems
- EU AI Act compliance assessment and documentation
- Executive dashboards in Power BI
- Business case development, ROI projection, stakeholder presentations
- Agile project management (Kanban, sprint delivery)
- AI use case scoping and validation framework
