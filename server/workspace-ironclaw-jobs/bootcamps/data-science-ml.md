# Data Science & Machine Learning Bootcamp

## Course Info
- **Duration:** 400 hours (360 + 40h prework), 9 weeks full-time
- **Level:** Beginner to Junior
- **DB slug:** `data-science-ml`

## Stack & Technologies
Python, Pandas, NumPy, Scikit-learn, TensorFlow, PyTorch/Keras, Matplotlib/Seaborn, Tableau, Plotly, SQL (SQLite/MySQL), OpenAI APIs, LangChain, ChromaDB, Streamlit, HuggingFace Transformers, MLOps concepts, OpenCV (computer vision), Jupyter Notebooks, Git/GitHub

## Key Skills
- Python programming for data science (OOP, functional programming, regex)
- Data wrangling and EDA with Pandas and NumPy
- SQL for data analysis (joins, subqueries, CTEs, window functions)
- Statistics and probability: hypothesis testing, regression analysis
- Supervised ML: linear/logistic regression, decision trees, SVMs, Random Forest, Gradient Boosting
- Unsupervised ML: clustering, dimensionality reduction
- Deep learning: neural networks, CNNs (computer vision), RNNs
- NLP: word embeddings, transformers (BERT-style models), text classification, sentiment analysis
- MLOps: model deployment workflow, experiment tracking
- Generative AI: prompt engineering, RAG systems, LLM applications (Streamlit)
