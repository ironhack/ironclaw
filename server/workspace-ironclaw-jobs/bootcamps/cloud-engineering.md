# Cloud Engineering Bootcamp

## Course Info
- **Duration:** 360 hours + 40h prework, 9 weeks full-time
- **Level:** Beginner to Junior
- **DB slug:** `cloud-engineering`

## Stack & Technologies
AWS (EC2, S3, IAM, VPC, Lambda, CloudWatch, EKS, RDS, Route53, CloudFormation, Cost Explorer), Terraform (IaC), GitHub Actions (CI/CD), Ansible, Helm, Prometheus, Grafana, OpenTelemetry, HashiCorp Vault (secrets), Keycloak (IAM), AWS Config, Docker, Kubernetes, Wazuh (intrusion detection), Git/GitHub, VS Code, Linux CLI, SSH

## Key Skills
- Linux system administration (CLI, SSH, permissions, shell scripting)
- AWS cloud infrastructure: compute (EC2), storage (S3), networking (VPC, subnets, load balancers), identity (IAM)
- Infrastructure as Code with Terraform (modules, state management, remote backends)
- CI/CD automation with GitHub Actions (GitOps workflows, pull request-driven deployments)
- Configuration management: Ansible, Helm
- Container orchestration: Docker, Kubernetes (deployments, services, namespaces, ConfigMaps)
- Observability: Prometheus metrics, Grafana dashboards and alerting, OpenTelemetry instrumentation
- FinOps: cost analysis (AWS Cost Explorer), rightsizing, tagging strategies
- Security and compliance: CIS/NIST/ISO 27001 frameworks, AWS Config, secrets management (Vault)
- **Certification alignment:** AWS Certified Cloud Practitioner, HashiCorp Terraform Associate

## Language Note
Cloud engineering roles at AWS ecosystem companies, cloud-native startups, and international tech firms are English-first. Cloud infrastructure is a global discipline — AWS, Terraform, and Kubernetes skills are what employers care about, not German fluency. AWS Certified Cloud Practitioner and Terraform Associate certifications strengthen a candidate's profile significantly. Key hubs: Frankfurt (AWS Germany HQ, fintech), Munich (enterprise tech, automotive cloud), Berlin (startup infrastructure).
