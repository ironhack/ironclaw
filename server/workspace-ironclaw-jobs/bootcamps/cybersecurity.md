# Cybersecurity Bootcamp

## Course Info
- **Duration:** 360 hours + 40h prework, 9 weeks full-time
- **Level:** Beginner to Junior
- **DB slug:** `cybersecurity`

## Stack & Technologies
Linux/Kali Linux, Splunk (SIEM), Wireshark, Nmap, Metasploit, BurpSuite, Ghidra (reverse engineering), Autopsy (digital forensics), Snort (IDS/IPS), Elastic Stack/Kibana, Python, Bash, PowerShell, Wazuh, TryHackMe platform, Volatility (memory analysis), NetworkMiner, Sysinternals

## Key Skills
- Network administration and traffic monitoring (VLANs, routing, subnetting)
- Cybersecurity principles: CIA Triad, Zero Trust, Defense in Depth
- Security tools: SIEM (Splunk), IDS/IPS (Snort), EDR, DLP, firewalls
- Cryptography: symmetric/asymmetric, hashing, VPNs, certificates
- Access control: Active Directory, RBAC, IAM
- Digital forensics: evidence acquisition, volatile/non-volatile memory analysis
- Malware analysis: static and dynamic analysis, reverse engineering (Ghidra)
- Ethical hacking: penetration testing (Metasploit, BurpSuite, Nmap)
- OWASP Top 10 web application vulnerabilities
- Incident response: identification, containment, eradication, recovery
- Threat intelligence: IOCs, OSINT, threat hunting (Shodan)
- Risk management and security governance
- Python and PowerShell scripting for security automation
- **Certification alignment:** CompTIA Security+, CISSP (ISC2)

## Language Note
Cybersecurity roles at international firms, MSSPs (Managed Security Service Providers), and tech companies are often English-first. SOC analyst and incident response roles at large German enterprises (banks, utilities, insurance) may require B1 German for internal reporting and stakeholder communication. CompTIA Security+ certification is a strong differentiator for junior roles and is internationally recognized. Key sectors: fintech/banking (Frankfurt), healthcare (Munich, Berlin), government/public sector.
