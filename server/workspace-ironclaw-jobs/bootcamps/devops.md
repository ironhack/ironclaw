# DevOps and Cloud Computing Bootcamp

## Course Info
- **Duration:** 400 hours (360 + 40h prework), 9 weeks full-time
- **Level:** Beginner to Junior
- **DB slug:** `devops`

## Stack & Technologies
Linux/Ubuntu CLI, Git/GitHub (GitFlow), AWS (IAM, VPC, EC2, S3, EKS, Lambda, RDS, DynamoDB, CloudWatch, CloudFormation, boto3/Python), Terraform (HCL, modules, remote state), Ansible (playbooks, roles, Jinja2, Vault), Docker, Docker Compose, Kubernetes (kubectl, Minikube, k9s), Amazon EKS (eksctl), GitHub Actions (CI/CD), SonarQube (code quality), Microsoft Azure (VMs, AKS, CLI, Entra/AAD, Terraform), Prometheus, Grafana, Grafana Loki, cAdvisor, Python

## Key Skills
- Linux system administration and shell scripting
- Git version control and GitFlow branching model
- AWS cloud infrastructure: IAM, VPC, EC2, Load Balancing, Lambda, S3, RDS, DynamoDB
- Infrastructure as Code: Terraform (variables, modules, state, meta-arguments)
- Configuration management: Ansible (playbooks, roles, Jinja2 templates, Vault for secrets)
- Containerization: Docker, Dockerfiles, multi-stage builds, Docker Compose
- Container orchestration: Kubernetes (pods, deployments, services, ConfigMaps, rolling updates)
- Managed Kubernetes: Amazon EKS and Azure AKS
- CI/CD pipelines: GitHub Actions, SonarQube code analysis
- Multi-cloud: AWS + Azure (VMs, networking, identity, governance)
- Monitoring and observability: Prometheus, Grafana dashboards/alerts, Grafana Loki (logging)
- Agile: Scrum ceremonies, sprint reviews, team collaboration

## Language Note
DevOps is a globally standardized discipline — Kubernetes, Terraform, and CI/CD knowledge are the differentiators, not language. International companies, cloud-native startups, and tech consultancies hire DevOps engineers in English. Key clusters: Frankfurt (fintech, AWS DE presence), Munich (BMW, Siemens, enterprise DevOps), Berlin (startups). Werkstudent DevOps roles at tech companies are a strong entry point and are frequently English-language.
